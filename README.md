# Fluxo Studio — website

Static, responsive product website for GitHub Pages. No build step or external dependencies.

- `index.html`: product page, Portuguese and English.
- `support.html`: support via this repository’s public GitHub Issues.
- `privacy.html`: privacy information for the current local-storage app.
- `assets/`: real app screenshots and an editable fictional sample.

## Preview

Run `python3 -m http.server 8080` from this directory and visit http://localhost:8080.

## GitHub Pages

In repository Settings → Pages, choose **Deploy from a branch**, branch **main**, folder **/ (root)**. Site: https://forappmobile.github.io/fluxostudio.io/

App Store: https://apps.apple.com/us/app/fluxo-studio/id6829978647
Support: https://forappmobile.github.io/fluxostudio.io/support.html
Privacy: https://forappmobile.github.io/fluxostudio.io/privacy.html

No analytics, advertising scripts, forms or external font dependencies. The language preference is stored locally in the browser. Interface screenshots are editorially cropped without changing app controls. The small hero flow is an illustrative interactive graphic, not the app editor.
