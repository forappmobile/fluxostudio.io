Precisa de ajuda com o Fluxo Studio ou tem uma ideia para compartilhar? Use nosso canal de suporte no GitHub para relatar um problema ou sugerir uma melhoria.

Abrir solicitação de suporte ↗

É necessário ter uma conta no GitHub para abrir uma solicitação. As solicitações são públicas.

Ajude a entender o que aconteceu

  • Conte o que estava tentando fazer e quais passos levaram ao problema.
  • Inclua a versão do app, o modelo do dispositivo e a versão do sistema.
  • Se ajudar, anexe uma captura de tela com todos os dados pessoais ou confidenciais removidos.

Antes de trocar de dispositivo

Os diagramas são armazenados localmente. Use o backup completo da biblioteca e guarde o arquivo exportado em um local seguro antes de apagar o app ou mudar de dispositivo.

Compartilhando um diagrama

Use PNG, PDF ou SVG quando a pessoa precisar apenas visualizar seu trabalho. Use o arquivo editável do diagrama quando quiser continuar a edição no Fluxo Studio.
